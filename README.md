# Janak Ajmera — Portfolio

Personal portfolio website showcasing my work, skills, experience, and projects as a Software Engineer.

The website is currently a frontend-only application built with React and Vite. It uses a terminal-inspired developer interface with a focus on simplicity and responsiveness.

## Features

- Terminal-inspired interface
- Light and dark themes
- Responsive design
